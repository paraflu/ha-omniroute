# OmniRoute Home Assistant Integration

Provides health and quota monitoring for your OmniRoute AI gateway.

## Features
- **Health Sensor**: Monitors the availability of the OmniRoute API.
- **Quota Sensors**: Dynamically tracks available quotas for configured AI providers.

## Installation
1. Install via HACS (Custom Component).
2. Restart Home Assistant.
3. Configure via the Integrations UI (provide Base URL and API Key).
